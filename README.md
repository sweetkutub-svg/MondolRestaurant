# Mondol Restaurant 🍽️

A luxury fine dining restaurant website for Mondol Restaurant, Kolkata.

## Features
- Beautiful responsive UI
- Signature dishes showcase
- Menu with filter tabs
- Online reservation form
- MySQL database integration

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MySQL

## Setup
1. Clone the repo
2. cd backend
3. npm install
4. Add your MySQL password in server.js
5. Run: node server.js
6. Open index.html with Live Server
